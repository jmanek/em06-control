ProtoArc EM06

EM06 Control

Profile and key remapping software for the ProtoArc EM06 trackball mouse.

Under active development

Features

  • Read and write all four mouse profiles.
  • Switch directly to any profile.
  • Automatically notice profile changes.
  • Use ProtoArc Hub functions, shortcuts, and custom key combinations.
  • Set any button to cycle profiles: 1 → 2 → 3 → 4 → 1.
  • Read and assign existing macro slots.

Use it

Open the EM06 Control app and connect the mouse in Chrome or Edge.

The project is still being improved. See the repository for the source and current status.

Reading does not write to the mouse. Profile reads and writes restore the previously active profile.
